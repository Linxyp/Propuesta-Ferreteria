# Propuesta Ferretería

Sitio estático publicado con GitHub Pages.

- `index.html` — la propuesta comercial.
- `demo/` — la plataforma completa funcionando en el navegador.

El demo no tiene servidor: los motores de cálculo, el cotizador, el bot, el
inventario y las finanzas corren del lado del cliente y guardan el estado en
la sesión del visitante. Cada quien ve su propia copia y puede crear pedidos
sin afectar a nadie más.

Generado con `npm run build:web` desde el proyecto `ferreteria-360`.
